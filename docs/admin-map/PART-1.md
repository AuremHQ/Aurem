# Admin Panel Map — Part 1: Inventory
Generated by code inspection on the current Preview branch. No code, config, flag or `.env` changes were made to produce this document.

## How to read this table

**Enforcement legend** (checked once, applies to every row unless a row says otherwise):
- Every `/admin/*` route in the React app is wrapped in `<AdminRoute>` (`components/PrivateRoute.jsx`), which checks `isAdminOrFounder()` from the decoded JWT **client-side only** — this is a UX redirect, not a security boundary (the component's own doc comment says so).
- Every backend router under `/api/aurem-dev/admin/*` (and the sibling `/ora-chat`, `/suggestions/admin`, `/scaffold/admin`, `/supabase/admin`, `/mcp` admin routes) enforces its own role check **server-side**, via one of two equivalent patterns confirmed by grep:
  - Router-level: `APIRouter(..., dependencies=[Depends(require_admin_dep)])` — confirmed in 24 of the 26 admin router files checked.
  - Per-function: `await require_admin(authorization)` called inside every route body — confirmed in `self_bugs_admin.py` and `admin_gateway.py` (the only two without the router-level form; functionally the same protection, just a different code shape — flagged as a style inconsistency in Part 4, not a gap).
- Net: enforcement is **"Both"** (screen-gate + server-gate) for every row below. Where I found an exception, it's called out explicitly in that row.

**Status legend** (I did not run a live click-through this turn — "code-verified" means I traced the exact frontend call to a registered, implemented backend function; it is not a substitute for a live Preview test):
- `WORKS (code-verified)` — frontend call(s) matched to a real, non-stub backend implementation.
- `PARTLY (code-verified)` — works, but a concrete gap/placeholder/inconsistency was found and is named in the row.
- `UNVERIFIED` — I could not trace this confidently from code in the time available; marked rather than guessed.

**Frontend base URL convention:** all `api.get/post/...` calls shown use the shared axios instance `api` (`lib/api.js`), whose base is `{REACT_APP_BACKEND_URL}/api/aurem-dev`. So a call like `api.get("/admin/users")` is `GET /api/aurem-dev/admin/users`. I've written paths in short form (`/admin/users`) in the table to keep it readable; prepend `/api/aurem-dev` for the real path unless noted.
