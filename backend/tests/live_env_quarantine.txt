# 2026-09-29 · CI-trustworthiness audit — root cause of the "Backend —
# pytest" job hitting its 15-minute cap (ci.yml `timeout -s INT 15m`).
# ci.yml's backend-tests job sets no REACT_APP_BACKEND_URL, so
# _resolve_live_base() (and each of these files' own
# os.environ.get("REACT_APP_BACKEND_URL", <hardcoded preview URL>)
# fallback) fell through to the COMMITTED frontend/.env value —
# https://aurem.onrender.com, a real, live, publicly-reachable
# deployment. _live_server_reachable()'s health probe returns 200
# against it, so the live_env skip never fired: these 80 files (found
# by grepping tests/ for the same REACT_APP_BACKEND_URL + requests.*
# pattern used by every already-quarantined file above, then
# diffing against this list) ran FOR REAL against that live
# deployment on every CI run — using CI's throwaway test account,
# against a database with completely different seeded state, each
# request taking real network + real endpoint latency (5-30s) instead
# of the near-0s a correctly-skipped test costs. ci.yml now also sets
# REACT_APP_BACKEND_URL to a guaranteed-refused loopback address for
# this job (see backend-tests job env) so the probe fails fast and
# uniformly instead of silently reaching a real, unrelated live
# server; this list is the other half of that fix — without it,
# these 80 files fail FAST instead of hanging, but still ERROR
# instead of cleanly SKIPping like every other live_env test.
