# RCA — run 6e3b2d46-75f0-4ed4-8285-61c3d3e106a5 (launch-pad-237)

## Summary
The redeploy failed at the **deploy_k8s** step with the backend pod in **CrashLoopBackOff (early), lastExit=1/Error**. Root cause is an **application source bug**, not infra/manifest/secrets. The backend aborts during import/startup, so the pod never becomes ready.

## Root cause (proven)
`/app/backend/routers/chat/turn.py`, endpoint `@router.post("/send")` (line 662), function `chat_send`, parameter at **line 670**:

```python
request: Optional[Request] = None,
```

FastAPI cannot treat `Optional[Request]` (i.e. `Union[Request, None]`) as a valid parameter type — it tries to build a Pydantic model field from it and raises at app-construction time:

```
fastapi.exceptions.FastAPIError: Invalid args for response field!
Hint: check that typing.Optional[starlette.requests.Request] is a valid Pydantic field type.
...
  File "/app/backend/routers/chat/turn.py", line 662, in <module>
    @router.post("/send")
```

This happens at module import (import chain: main.py → routers_registry.py → routers/chat/__init__.py → routers/chat/turn.py), so uvicorn exits immediately → `Backend failed to start at initialization, exiting` → CrashLoopBackOff.

The parameter was changed in the "P0 audit fix (2026-11-25, D1/D2)" to make `request` optional for non-HTTP callers.

## Reproduced in sandbox (eph pod, fastapi==0.115.0 — same as backend/requirements.txt)
```
request: Optional[Request] = None   -> BAD raises: FastAPIError   (matches prod crash)
request: Request = None             -> FIX ok: bare Request = None works
```

## Fix (Code — E1 applies)
In `/app/backend/routers/chat/turn.py`, change line 670 from:
```python
request: Optional[Request] = None,
```
to a bare `Request` with a default (FastAPI recognizes `Request` as a special injectable and ignores the default; the Optional wrapper is what breaks it):
```python
request: Request = None,
```
This preserves the intended behavior — FastAPI injects the real request on HTTP calls, and direct/non-HTTP callers still pass `None`. The existing `if request is not None` guard below keeps working unchanged. (`from typing import Optional` may now be unused in this file — clean up if desired.)

After the edit, redeploy. No manifest, secret, tier, or infra change is needed.
